# E17 · 前端内存泄漏

**级别**：bug ｜ **期望路由**：`debugging` → `verification`

## 输入
「页面来回切几次就越来越卡，内存一直涨。」

## 期望行为
- 反馈环：无头浏览器脚本（Playwright / Puppeteer）来回切换 N 次并断言堆大小 / 监听器数量 / DOM 节点数。
- 最小化：逐个移除订阅、定时器、事件监听、未取消的请求，定位承重的那个。
- 修复后资源在卸载时清理，并补回归测试（或说明为何难以自动化，转为手工验证步骤）。

## 判定（任一为否即 Fail）
- [ ] 有可重复的检测脚本，不是"我看了下 useEffect"
- [ ] 覆盖了监听器 / 定时器 / 订阅 / 未取消请求几类来源
- [ ] 修复落在清理逻辑上，不是靠隐藏组件规避
- [ ] 说明了如何验证修复（自动化或明确的手工步骤）
