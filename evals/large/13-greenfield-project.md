# E13 · 从零搭一个新项目

**级别**：large ｜ **期望路由**：`requirements` → `architecture` → `implementation` → `verification`

## 输入
「我要做一个 SaaS，帮我从零搭起来。」（无既有代码库）

## 期望行为
- 需求补全后先产出 PRD / ADR，再动代码（这是大任务该有的尺度）。
- 技术选型默认更简单的一侧（单体、关系型、同步），引入任何基础设施写明收益与成本。
- 骨架即可运行 + 可测试：一条命令起服务、一条命令跑测试。
- 领域术语落到 `CONTEXT.md`。

## 判定（任一为否即 Fail）
- [ ] 先有 PRD / ADR 再写代码
- [ ] 没默认上 K8s / 微服务 / 事件总线
- [ ] 骨架可运行且可测试，有验证命令
- [ ] 建立了 `CONTEXT.md`
- [ ] 附了风险清单与后续待办
