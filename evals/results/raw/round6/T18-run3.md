# 团队协作工具 · 项目命名提案

## 一、首选推荐（英文，短、好念、可注册）

| 名字 | 读音/构词 | 寓意与适配场景 | 备注 |
|---|---|---|---|
| **CoFlow** | co + flow | 协作像流水一样顺畅，强调“减少阻塞、信息流动” | 与任务流/自动化强相关，建议首选 |
| **Tandem** | /ˈtændəm/ | tandem bike 双人协力，天然带“配合”意象 | 已有若干同类产品，需查商标 |
| **Huddle** | 围成一圈 | 三五人快速对齐，适合轻量站会/即时沟通 | 已有一款体育协作 App 同名 |
| **Orbit** | 轨道 | 团队围绕同一目标运转，有“引力/向心力” | 存在 Orbit（社区运营） |
| **Relay** | 接力 | 强调交接、异步协作、跨时区接力 | 与“轮值/交接”场景契合 |
| **Weave** | 编织 | 把人、任务、文档织在一起 | 语义柔和，视觉好延展 |
| **Nexus** | 连接点 | 团队信息的中枢 | 较常见，区分度一般 |
| **Ally** | 盟友 | 强调人与人之间的信任与互助 | 简短有力，但易被占用 |
| **Beacon** | 灯塔 | 项目进展透明、方向清晰 | 适合偏“进度可视化”定位 |
| **Pylon** | 塔架 | 基础设施感，稳 | 偏技术向 |

## 二、偏中文 / 可中英双关

1. **同频（Tonewave / Samewave）** — 团队在同一频率上沟通
2. **协奏（Concerto / Coplay）** — 各司其职又成整体
3. **合木** — 独木不成林，合木成林
4. **众行** — 独行快，众行远
5. **一格** — 一人一格，拼成完整画面
6. **星阵** — 各自发光，又能成阵
7. **桥岛** — 连接一座座信息孤岛
8. **接力社 / 接棒** — 异步协作的直接意象

## 三、造词法（可自由组合、注册友好）

- 前缀：`Co-` `Syn-` `We-` `Uni-` `All-` `Team-`
- 后缀：`-ly` `-ify` `-io` `-hub` `-space` `-work` `-desk`

拼接示例：Synkly、Cohey、Teamio、Allboard（all + onboard）、Coplane、Syncpad、Workloom。

## 四、命名检查清单（定名前务必过一遍）

1. **两秒可读**：口头念一遍，对方能拼出来吗？
2. **域名**：优先 `.com`，其次 `.app` / `.io`；被占就加 `get-` / `-hq`，不要换怪拼写（Kwiq 这类）。
3. **商标**：在中国商标网 / USPTO 检索第 9、42 类。
4. **语义污染**：目标市场的语言里有没有歧义或贬义。
5. **可延展**：以后加 IM、文档、OKR、AI 助手，名字还撑得住吗？
6. **视觉**：首字母能否做成图标（如 CoFlow 的双箭头/波纹）。
7. **搜索度**：搜这个名字，前两页是不是已被同类产品占满。

## 五、我的 Top 3

1. **CoFlow** — 流畅、现代，与“协作流”强绑定，扩展性最好
2. **同频 / Tonewave** — 中文语感好，贴合国内团队文化
3. **Relay** — 直接命中“异步协作、跨时区交接”这个真实痛点
