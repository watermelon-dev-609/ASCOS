# E03 · 改配色（Design Token）

**级别**：small ｜ **期望路由**：`implementation` → `verification`

## 输入
「主色调从 #1677ff 改成 #0052d9。」

## 期望行为
- 只改 Design Token（变量 / 主题配置），不散改各组件里的魔法值。
- 检查是否有地方绕过 token 硬编码了该色值。
- 提示对比度 / 无障碍影响（这是合理的补全，不是扩大范围）。

## 判定（任一为否即 Fail）
- [ ] 改的是 token 而不是逐处硬编码
- [ ] 找出并清理了绕过 token 的硬编码点
- [ ] 说明了对比度 / 无障碍风险或已验证
- [ ] 没有引入新的主题系统 / CSS-in-JS 依赖
