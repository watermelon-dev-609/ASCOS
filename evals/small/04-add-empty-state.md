# E04 · 补一个空状态

**级别**：small ｜ **期望路由**：`implementation` → `verification`

## 输入
「订单列表为空的时候现在是一片白，加个空状态吧。」

## 期望行为
- 复用项目既有 Empty 组件 / 四态约定，不新造一套。
- 空状态文案与引导动作（如"去创建订单"）合理，并考虑无权限与加载中的区分。
- 低风险改动：测试深度可只做冒烟，但必须说明判定依据。

## 判定（任一为否即 Fail）
- [ ] 复用了既有组件而不是新建一个
- [ ] 区分了「空数据」与「加载中 / 报错 / 无权限」
- [ ] 没有为这个小改动写 TEST_PLAN
- [ ] 测试深度与风险匹配（没过度测试，也没零验证就交付）
