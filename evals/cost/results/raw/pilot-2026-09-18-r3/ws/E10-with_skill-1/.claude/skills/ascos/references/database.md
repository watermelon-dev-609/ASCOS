# 数据库规范

## 建模
- 以业务不变量与查询模式驱动建模；先定实体、关系与约束，再定表 / 索引。
- 明确主键、外键、唯一约束、非空约束。

## 查询
- 参数化查询，禁止字符串拼接 SQL / NoSQL。
- 为高频 / 慢查询建立必要索引；避免 SELECT * 与 N+1。
- 大结果集分页；写操作考虑批量与事务边界。

## 一致性
- 多步写用事务保证一致性；并发更新用乐观锁 / 行锁避免丢失更新。
- 明确读写一致性与隔离级别需求。

## 变更
- Schema 变更走迁移脚本，可回滚；生产变更需评估锁表 / 数据量影响。
- 敏感字段加密存储；密钥不入库。
