# Quality Model

ASCOS avoids fake precision. It does not require arbitrary scores such as “95/100”.

Use three levels:

- **Blocker** — unsafe or incorrect; must fix before delivery.
- **Important** — significant maintainability, UX, performance or operational weakness; fix if proportionate, otherwise disclose.
- **Optional** — future enhancement.

This prevents endless self-iteration while preserving meaningful quality gates.
