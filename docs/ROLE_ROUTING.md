# Role Routing Guide

| Task | Minimum roles |
|---|---|
| CSS/layout bug | Frontend, UX, Reviewer |
| New CRUD module | Product, DB, Backend, Frontend, QA, Reviewer |
| Login / RBAC | Architect, Backend, Security, QA, Reviewer |
| Payment / billing | Product, Backend, DB, Security, QA, Compliance, CTO |
| RAG / knowledge base | Product, AI, Data, Backend, Security, QA |
| Production outage | DevOps/SRE, relevant Engineer, Reviewer |
| Large greenfield system | Product, UX, Architect, DB, Backend, Frontend, Security, QA, DevOps, CTO |

Roles are capability modules. Add or remove roles based on actual need.
