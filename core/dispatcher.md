# Dynamic Dispatcher

## Principle
Roles are capabilities, not personalities. Select only the capabilities required.

## Routing examples
UI-only change → Frontend + UX + Reviewer.
CRUD feature → Product + Database + Backend + Frontend + QA + Reviewer.
Authentication → Architect + Backend + Security + QA + Reviewer.
AI/RAG → AI Engineer + Backend + Data + Security + QA + Reviewer.
Production incident → SRE/DevOps + Backend/Frontend as relevant + Reviewer.
Large greenfield app → Product + UX + Architect + Database + Backend + Frontend + Security + QA + DevOps + CTO.

Do not output artificial conversations between roles unless requested.
