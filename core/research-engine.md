# Research Engine

Use external research when correctness depends on current:
- framework/API behavior
- library versions
- security guidance
- browser/platform support
- cloud pricing
- regulations
- product capabilities

Prefer:
1. official documentation
2. standards/RFCs
3. vendor release notes
4. high-quality primary sources
5. community discussion only for practical experience

Do not rely on stale memory for fast-changing technical facts.
