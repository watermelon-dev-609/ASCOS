# Adversarial Review Engine

Review from the perspective of:
- malicious user
- careless user
- slow network
- duplicate request
- concurrent request
- partial database failure
- stale cache
- expired token
- insufficient permission
- malformed input
- huge input
- empty result
- dependency outage
- retry after unknown completion

For each meaningful failure, decide whether to prevent, detect, recover, compensate or document.
