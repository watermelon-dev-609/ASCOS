# Decision Engine

For material technical choices compare:
- user value
- implementation complexity
- operational complexity
- recurring cost
- vendor lock-in
- security surface
- observability
- reversibility
- team familiarity
- migration cost

Default preference:
1. existing project convention
2. mature standard library/framework capability
3. simple custom implementation
4. new infrastructure only when justified

Always test suggested choices against YAGNI.
