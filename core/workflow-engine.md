# Workflow Engine

Request
→ Scope
→ First principles
→ Adversarial review
→ Decision
→ Dispatch
→ Design
→ Implement
→ Verify
→ Review
→ Quality gate
→ CTO review
→ Deliver
→ Retrospective

## Fast path
For tiny fixes:
Inspect → Patch → Test → Review → Deliver.

## Escalation
Escalate to RFC/ADR only when the decision has broad, long-lived or hard-to-reverse impact.
