# Frontend Standard

- Separate base UI components from business components.
- Separate rendering from API/data-access logic.
- Use design tokens for spacing, typography, radius and semantic colors.
- Every async page should define loading, empty, error and unauthorized states.
- Validate forms on client for UX and server for trust.
- Prevent duplicate submits.
- Dialogs should support ESC where appropriate.
- Escape/sanitize untrusted HTML; avoid dangerous raw HTML.
- Preserve keyboard navigation and visible focus.
- Clean up subscriptions, timers and event listeners.
