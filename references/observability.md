# 可观测性强化（Observability）— P2

在已有日志与监控意识基础上进一步标准化。

## 实践
- 结构化日志（机器可解析的字段）。
- 请求 / 任务关联 ID（便于链路串联）。
- 关键业务指标（成功率、延迟、错误率）。
- 依赖失败与超时监控。
- 健康检查端点。
- 必要时链路追踪（分布式场景）。

## 原则
- 按任务规模取舍；简单服务不必过度埋点。
- 日志必须脱敏（见 `security.md`）：口令、token、手机号、身份证等不落日志。
