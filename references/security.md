# 安全规范

## 鉴权与授权
- 身份由服务端签发与识别；token / 会话安全（过期、刷新、吊销）。
- 前端仅控制权限**展示**；所有敏感操作后端再次校验权限。
- 默认拒绝（deny by default）：无显式授权即拒绝。

## 输入与注入
- 所有外部输入校验（类型 / 长度 / 范围 / 白名单）。
- 参数化查询防 SQL / NoSQL 注入；拒绝请求体中的操作符对象。
- 渲染层转义 / 白名单 sanitize 防 XSS；不信任任何用户输入。

## 数据与日志
- 敏感数据加密存储与传输（HTTPS）；密钥走环境变量，禁止硬编码。
- 日志脱敏：口令、token、手机号、身份证等不落日志。

## 越权防护
- 对象级鉴权：不仅验证「是否登录」，还要验证「是否拥有该资源」。
- 防范 IDOR（通过可枚举 ID 越权访问他人数据）。
- 文件上传校验类型 / 大小 / 内容，防路径穿越。
