# 后端规范

## 分层与契约
- 接口契约先行，统一 Result 契约 `{ ok, code, msg, data }`。
- 业务逻辑与 IO 分离；业务层不依赖具体存储实现。

## 输入与安全
- 所有外部输入必须校验（白名单 / 长度 / 类型 / 范围）。
- 配置与密钥一律放环境变量 / 配置中心，**禁止硬编码密钥**。
- 参数化查询防注入；拒绝请求体中的操作符对象（如 `$ne` / `$regex`）。

## 可靠性
- 幂等：重复请求不产生副作用（如唯一幂等键）。
- 事务：多步写操作失败整体回滚。
- 并发竞态：乐观锁 / 事务 / 原子操作。
- 日志脱敏：不回显内部错误、口令、手机号等敏感字段。

## 鉴权授权
- 身份由服务端签发与识别（如会话 / token）；前端仅控制展示，真实权限校验只在后端。
