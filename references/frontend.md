# 前端规范

## 组件
- 拆分基础组件与业务组件；UI 渲染与接口 / 数据访问逻辑分离（统一请求层封装）。

## 样式
- 使用 Design Token 统一样式（颜色 / 间距 / 圆角走变量，不散写魔法值）。

## 四种状态（页面必须覆盖）
- Loading / Empty / Error / 无权限（NoPermission）。

## 表单与交互
- 前端表单校验 + 提交防重复（防抖 / loading 锁）。
- 弹窗支持 ESC 关闭。
- XSS 防护：渲染层转义 / 白名单 sanitize，不信任任何用户输入。

## 安全与资源
- 前端仅控制权限**展示**；真实权限校验只在后端。
- 资源自动释放：监听器 / 定时器 / 订阅在卸载时清理。

## 可访问性
- 关键交互支持键盘可达（合理范围内）。
